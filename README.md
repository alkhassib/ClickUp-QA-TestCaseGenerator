# أتمتة توليد التست كيسز من ClickUp

سكربت بايثون (بدون n8n) يسحب قصص المستخدم الجاهزة من ClickUp، يولّد تست كيسز عبر
LangChain + GPT-5 Nano، وينشئها كتكتات جديدة رجوع على ClickUp.

## هيكل المشروع

```
config.py         تحميل الإعدادات من .env
models.py         مخططات Pydantic (شكل ثابت لمخرجات الموديل)
prompts/          البرومبتات الثلاث (منفصلة عن الكود، سهلة التعديل)
llm_chain.py       السلاسل الثلاث: فحص وضوح -> توليد -> مراجعة ذاتية
clickup_client.py  غلاف بسيط حول ClickUp API v2
pipeline.py        معالجة قصة مستخدم وحدة من البداية للنهاية
main.py            نقطة التشغيل + حلقة الفحص الدوري (polling)
```

## خطوات الإعداد

1. **تثبيت المكتبات**:
   ```
   pip install -r requirements.txt
   ```

2. **نسخ ملف الإعدادات**:
   ```
   cp .env.example .env
   ```

3. **تعبئة `.env` بالقيم الحقيقية**:
   - `CLICKUP_API_TOKEN`: من ClickUp -> Settings -> Apps -> Generate
   - `CLICKUP_TEAM_ID`: معرف الـ Workspace (من رابط ClickUp أو استدعاء `GET /api/v2/team`)
   - `SOURCE_LIST_ID`: معرف اللست اللي فيها قصص المستخدم
   - `INPUT_COLUMN`: اسم الحالة اللي بتشغل الفلو (لازم يطابق بالضبط اسمها بـ ClickUp)
   - `OUTPUT_LIST_ID`: وين بتتولد تكتات التست كيسز (نفس `SOURCE_LIST_ID` أو List ID مختلف)
   - `OUTPUT_COLUMN`: الحالة اللي بتتحط على تكتات التست كيسز الجديدة
   - `STORY_DONE_COLUMN`: الحالة اللي قصة المستخدم بتتحرك لها بعد الانتهاء
   - `OPENAI_API_KEY`: مفتاح OpenAI

4. **شغّل أول مرة بوضع تجربة** (`DRY_RUN=true` بالـ `.env`):
   ```
   python main.py
   ```
   راقب ملف `automation.log` — رح يطبعلك أسماء التست كيسز اللي كان رح تتولد
   بدون ما يكتب أي شي فعلياً على ClickUp.

5. **لما تتأكد إن النتائج منطقية**، غيّر `DRY_RUN=false` وشغّل من جديد.

## ملاحظة مهمة عن الموثوقية

لو صار خطأ بمنتصف إنشاء التست كيسز لقصة معينة (بعد ما اتنشأ بعضهم وقبل ما يخلص)،
السكربت **ما بيحدث حالة القصة الأصلية** عشان يعيد المحاولة بالدورة الجاية — بس هاد معناه
احتمال يتكرر إنشاء التست كيسز اللي كانت نجحت قبل الفشل. لو صار هيك، السجل (log) بيوريك
بالضبط أي تكتات اتنشأت قبل الفشل عشان تراجعها/تحذفها يدوياً. هاي نقطة تحسين مستقبلية
(مثلاً بإضافة custom field على القصة يسجل التست كيسز اللي اتنشأت لحد هلأ).

## اختبار محلي

المشروع اتفحص بالكامل (صياغة + استيراد + بناء الكائنات) داخل بيئة التطوير، لكن
**ما تم اختباره باستدعاءات حقيقية لـ ClickUp أو OpenAI** لأن بيئة التطوير ما عندها
وصول شبكة لهاد النطاقات. جرّبه بوضع `DRY_RUN=true` أول شي عندك عشان تتأكد كل شي شغال
قبل ما تعتمد عليه فعلياً.
